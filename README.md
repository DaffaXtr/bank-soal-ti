# Bank Soal & Modul Belajar Mandiri Teknik Informatika (Clean Architecture)

Platform pembelajaran mandiri dan bank soal Teknik Informatika tanpa sistem login (*zero-friction*), dirancang dengan **Clean Architecture**, desain modern bebas bayangan (*100% zero-shadow*), dan aturan rasio warna **60-30-10** (60% Putih, 30% Hitam, 10% Biru).

## 🌟 Fitur Unggulan

1. **Dua Mode Pengerjaan Interaktif**:
   - 📖 **Mode Belajar (Study Mode)**: Umpan balik benar/salah seketika dan kotak pembahasan materi mendalam.
   - 📝 **Mode Simulasi Ujian (Exam Mode)**: Pembahasan disembunyikan sampai submit, pengerjaan mandiri tanpa batas waktu/timer.
2. **Dukungan Format Informatika**: Blok kode monospaced (`pre`/`code`) untuk logika algoritma & pemrograman.
3. **Penyimpanan Lokal Tanpa Login (`LocalStorage`)**:
   - Riwayat & statistik skor pengerjaan
   - Bookmark / Simpan soal sulit
   - Tombol **"Latih Ulang Soal yang Salah"** (*spaced repetition*)
4. **Sidebar Navigasi Semester 1–5**: Pemfilteran instan dan kotak pencarian mata kuliah.
5. **Pengacakan Soal & Jawaban Otomatis (Fisher-Yates Shuffle)**: Setiap kali membuka sesi baru atau menekan tombol Reset Jawaban, **urutan soal dan urutan pilihan jawaban (A, B, C, D, E)** otomatis diacak secara adil dan matematis tanpa bias. Label huruf tetap tersusun rapi A, B, C, D, E sementara kunci jawaban tetap terjaga akurat.
6. **Hash Routing & Tombol Reset Jawaban**: Mendukung rute URL per semester (`#/semester/5`), per paket ujian (`#/exam/sem5-sqa-uts`), dan per butir soal (`#/exam/sem5-sqa-uts/12`). Saat halaman di-refresh di tengah pengerjaan, urutan acak dan progres tetap tersimpan aman. Jika ingin mengulang dari awal dengan acakan baru, cukup tekan tombol **"Reset Jawaban"** di bar atas ruang ujian.

## 🛡️ Keamanan Ujian & Anti-Inspect Blocker

Sistem dilengkapi proteksi di berkas `js/infrastructure/AntiInspect.js` untuk mencegah pembocoran kunci jawaban:

### 1. Anti-Inspect & DevTools Blocker
- **Blokir Klik Kanan (`contextmenu`)**: Mencegah menu *Inspect Element*.
- **Blokir Shortcut Keyboard**: `F12`, `Ctrl + Shift + I/J/C`, `Ctrl + U`, `Ctrl + S`, `Ctrl + P`.
- **Debugger Trap Loop**: Memicu breakpoint otomatis untuk membekukan eksekusi tab jika DevTools dibuka paksa lewat menu browser.
- **Console Auto-Clear**: Membersihkan log konsol setiap 3 detik.

### 2. Anti-Copy & Anti-Cut
- Mencegah peserta menyalin teks soal (`Ctrl + C` atau blok teks). Jika dipaksa, clipboard otomatis diganti dengan teks edukasi:  
  *"Menyalin konten soal tidak diperbolehkan demi integritas ujian."*

### 3. Mode Layar Penuh (Fullscreen)
- Tombol **"Layar Penuh"** tersedia di header ruang ujian untuk memaksimalkan fokus pengerjaan tanpa gangguan bilah alat browser.

### 4. Mode Khusus Pengembang (Bypass)
Jika Anda sebagai pengembang ingin melakukan debugging dan membuka DevTools tanpa terhalang proteksi, cukup tambahkan parameter `?debug=true` pada URL:  
`index.html?debug=true`  
atau jalankan `localStorage.setItem('allow_devtools', 'true')` di browser. Proteksi akan otomatis nonaktif khusus untuk sesi tersebut.

## ✍️ Cara Menambahkan Soal Baru (Sangat Mudah & Rapi)

1. Buat berkas baru di dalam folder `data/questions/` dengan format nama:  
   `{id-matkul}-{kategori}.js`  
   *(Contoh: `data/questions/sem2-logpro-uts.js`)*
2. Tulis soal mengikuti contoh pada [data/questions/template-soal.js](file:///d:/UNAIR/KULIAH/PROJECT%20MANDIRI/Bank-soal/data/questions/template-soal.js):
   ```javascript
   window.BankSoalData = window.BankSoalData || {};
   window.BankSoalData.questions = window.BankSoalData.questions || {};

   window.BankSoalData.questions['sem2-logpro-uts'] = [
     {
       no: 1,
       soal: "Tipe data bilangan bulat di C++ adalah...",
       codeSnippet: "int a = 10;", // opsional (boleh null jika tidak ada kode)
       pembahasan: "int digunakan untuk bilangan bulat.",
       opsi: [
         { huruf: "a", teks: "int", benar: true },
         { huruf: "b", teks: "float", benar: false }
       ]
     }
   ];
   ```
3. Daftarkan file script tersebut di [index.html](file:///d:/UNAIR/KULIAH/PROJECT%20MANDIRI/Bank-soal/index.html) tepat di bagian data layer:
   ```html
   <script src="data/questions/sem2-logpro-uts.js"></script>
   ```
4. Soal langsung aktif dan terhubung ke mata kuliah terkait tanpa perlu menyentuh logic aplikasi!
